# App fechado para dois usuários

O app atende só o Flávio e a esposa: não tem cadastro público, não separa dados por lar (multi-inquilino) e não prepara o desenho para outros casais, nem como objetivo futuro. Desenhar para vários lares custaria isolamento de dados, cadastro e permissões em todo o modelo para um uso que não existe; o cuidado de engenharia vai para o histórico longo de dados, não para escala de usuários.

## Consequences

- Abrir o app para outras pessoas é um esforço novo, que começa reabrindo esta decisão.
